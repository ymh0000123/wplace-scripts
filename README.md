# wplace 脚本合集

[wplace.live](https://wplace.live) 的用户脚本（油猴 / ScriptCat）合集。

## 脚本列表

### [wplace-overlay-autocolor.user.js](wplace-overlay-autocolor.user.js) — 覆盖图自动选色

把官方模板覆盖图变成可交互的参照层，悬停像素时自动从色板选中对应颜色，省去反复对照取色。

**工作原理**：Hook WebGL `texImage2D` 捕获官方模板覆盖瓦片的纹理数据，按绝对定位归属到世界像素坐标；视角变化时通过 uniform 重放自动贴合，无需重新捕获。

**主要功能**：

- **自动选色**：鼠标悬停在覆盖图像素上时，自动在色板中选中该点应使用的颜色（可用「悬停换色」开关关闭）
- **参照层绘制**：即使官方覆盖图缩放模糊，也按世界坐标重绘像素网格；视角移动时实时贴合
- **对齐校准（🎯）**：别人已把图案画在画布上时，一键把模板对齐到已画内容：
  - Hook 官方地图瓦片请求（`/files/s{n}/tiles/{x}/{y}.png`，与官方 auto-paint 同一数据源），零额外流量缓存画布真实像素
  - 与模板量化像素逐点比对，两级搜索（步长 4 粗搜 → 邻域精搜）算出位置偏移 δ（世界像素，±48 范围）
  - 匹配率 = 已涂像素中的颜色正确率，与官方 auto-paint 一致逐字节精确比较；阈值不足则拒绝应用
  - 参照层立即平移 δ 预览效果；点「✅ 应用对齐」把偏移写入官方模板 bounds（`template-overlays`），刷新页面后官方覆盖图精确落到已画内容上
  - 同时统计 **已画对 / 画错 / 未画** 并在参照层叠加高亮（绿=已对、红=画错、蓝=未画）；画错像素全部为免费色板色时提示把色板改用「免费颜色」
- **指哪改哪**：校准生效后悬停画错的像素，HUD 直接显示「画布色 ≠ 目标色」并自动选中正确颜色；已画对的像素不再触发换色
- **锁定色过滤**：已锁定的颜色不参与自动选中
- **已选中色防误触**：点击当前已选中的色块不会触发官方的视角飞行
- **覆盖模式退出检测**：官方覆盖图停止渲染（退出覆盖模式 / 隐藏模板 / 移出视野）时参照层自动收起，恢复后自动重现
- **状态悬浮窗（HUD）**：
  - 可折叠为一行小胶囊，`Ctrl+Shift+H` 一键折叠 / 展开（无论拖到哪都能找回）
  - 折叠状态与悬浮窗位置跨刷新记忆
- **手动定位**：`Ctrl+点击` 地图任意位置，按覆盖图数据定位该处的参照层

**对齐校准推荐流程**：官方放置模板（位置大致放到已画图案附近）→ 滚动地图让官方加载该区域瓦片 → 点「🎯 校准」→ 核对匹配率与偏移 → 点「✅ 应用对齐」→ F5 刷新 → 对照红/绿高亮改正画错的颜色。

**放置编辑面板里也能校准（v2.5.2/v2.5.3）**：官方编辑器的模板预览是 DOM 2D canvas（不走 WebGL），且沙箱环境下 fetch 拦截不可靠——脚本改为：模板纹理直接快照编辑器 canvas（内容已是量化+色板+抖动+翻转的最终像素），画布数据按范围**主动拉取**官方瓦片（实测 CORS 可直连）。基准位置优先取 localStorage 同尺寸模板的已存 bounds（=实际放置处），偏差交给**阶梯半径搜索**（±96 步长4 → ±288 步长8 → ±1120 步长16+邻域细化，逐级显著性判断、命中即停）。校准全程在**快查网格**上运行（画布范围一次性栅格化为调色板索引数组，搜索查询退化为数组下标读——v2.5.2 实测 5000 万次瓦片查询会冻结主线程 30 秒+），分批让出主线程不卡界面。**假峰守门**：匹配率需显著高于背景噪声才接受（实测空白画布上 36% 噪声峰会骗过固定阈值），拒绝时给出行动指引。校准 → 参照层屏幕空间平移预览 → 点官方「应用」保存 → 脚本自动把最终位置写入（F5 生效）。已放置模板的普通模式校准同样改为主动拉取数据，不再依赖 fetch 拦截。

**操作方式**：拖动 HUD 标题栏移动悬浮窗；点击「—/▸」折叠展开；`Ctrl+Shift+H` 键盘找回。

### [wplace-zh.user.js](wplace-zh.user.js) — 界面汉化

wplace.live 界面中文化。站点自带的中文语言包在隐藏菜单里，本脚本通过 `localStorage.PARAGLIDE_LOCALE = 'ch'` 启用并补充翻译。

## 安装

1. 浏览器安装 [ScriptCat](https://scriptcat.org/) 或 Tampermonkey
2. 新建脚本，粘贴对应 `.user.js` 文件内容并保存
3. 打开 wplace.live 生效

## 本地测试

```bash
node test_capture.mjs    # 捕获管线回归（22 项）：WebGL 捕获 → 坐标归属 → uniform 重放
node test_uifixes.mjs    # UI 状态机仿真（23 项）：覆盖模式检测 / 折叠 / 位置记忆
node test_calib.mjs      # 对齐校准仿真（235 项）：坐标换算 / 偏移搜索 / 状态统计 / bounds 写回 / 编辑会话与主动补抓 / 风格识别 / 触摸拖动 / 框选补画
node check_refs.cjs      # 标识符定义/引用计数一致性校验
```

测试不依赖浏览器：`test_capture.mjs` 复刻官方渲染时序做管线仿真，`test_uifixes.mjs` 用虚拟时钟驱动 UI 状态机，`test_calib.mjs` 构造"已画好但偏移 (7,3) 且有画错像素"的仿真画布端到端验证校准。
